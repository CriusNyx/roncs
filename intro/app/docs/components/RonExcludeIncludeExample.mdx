## RonExclude / RonInclude

Include or exclude members from ron serialization.


<CodeExample>
<CodeBlock lang='C#'>
```cs
public class MyClass{
  [RonExclude]
  public string excludeMember;
  [RonInclude]
  private string includeMember;
}

var value = new MyClass{
  excludeMember="I will not be serialized",
  includeMember="I will be serialized",
};
```
</CodeBlock>

<CodeBlock lang='Ron'>
```rs
MyClass(
  // Included in generated Ron
  includeMember: "I will be serialized"
)
```
</CodeBlock>
</CodeExample>
