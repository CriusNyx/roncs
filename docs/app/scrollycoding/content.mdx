## !intro Scrollycoding Example

Ron CS is a Serialize and Deserializer so that you can save and load .NET objects using RON.

## !!steps Ron CS

CS

```cs
Player player = new Player {
  children = [
    new PlayerInfo {
      name = "Frodo"
    }
    new PlayerController(),
    new Health{
      maxHealth = 100,
      currentHealth = 75
    }
    new Collider(),
  ]
};

string ron = Ron.Serialize(player);
```
